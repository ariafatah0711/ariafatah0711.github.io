Source code on GitHub GitHub profile

Dari Jekyll ke Eleventy

Website ini bermula dari Ephesus Jekyll Theme buatan Hakan Torun, kemudian dikustomisasi dan dikembangkan untuk kebutuhan portfolio pribadi.

Runtime dan build pipeline-nya kini telah direfaktor penuh oleh ariafatah0711 dari Jekyll/Ruby ke Eleventy/Node.js. URL, konten, feed, integrasi browser, dan identitas visual dipertahankan, tetapi Jekyll, Ruby, serta Bundler tidak lagi dipakai pada implementasi aktif.

Implementasi Sekarang

Runtime
Node.js 24 dan Eleventy 3
Templates
Liquid, HTML, Markdown, dan data YAML
Styling
Component CSS dengan fondasi Tailwind CSS v4 tanpa Preflight
Testing
Integrity checks dan Playwright visual regression
Deployment
GitHub Actions dan GitHub Pages

Kredit dan Riwayat

Ephesus tetap dikreditkan sebagai fondasi visual awal. Implementasi Eleventy, migrasi konten, compatibility layer, pengujian parity, dan pengembangan berikutnya dikerjakan serta dipelihara di repository GitHub ariafatah0711.
