## Tentang NXCTF

[NXCTF](https://nxctf.my.id/) adalah ekosistem open source untuk membangun, menjalankan, dan
meningkatkan skala kompetisi Capture The Flag serta pelatihan cybersecurity. Project ini
menghubungkan platform kompetisi, infrastruktur challenge, dan tool operasional agar organizer
tidak perlu merangkai semuanya dari nol.

Saya membangun NXCTF sebagai founder dan lead developer. Fokus saya bukan hanya membuat halaman
challenge dan scoreboard, tetapi juga menyederhanakan pekerjaan di belakang sebuah event: mulai
dari pengelolaan tim dan event sampai deployment service challenge yang terisolasi.

## Perjalanan Project

Project ini berawal dari CWA (CTF Web Aria), eksperimen untuk membuat platform CTF yang dapat
di-host dengan biaya rendah menggunakan layanan seperti Vercel dan Supabase. Eksperimen tersebut
kemudian berkembang menjadi CTFS (Capture The Flag Simple) dan digunakan pada beberapa event.

Pada Mei 2026, saya melakukan rewrite dan rebranding menjadi NXCTF. Perubahan ini memperluas
arah project dari satu aplikasi menjadi ekosistem yang dapat dipakai bersama oleh platform,
infrastruktur, dan automation tooling.

## Bagian Utama Ekosistem

- [NXCTF](https://github.com/nxctf/nxctf) adalah core platform untuk mengelola multiple event,
  challenge, tim, scoreboard, dynamic scoring, dan workflow admin.
- [NXCTL](https://github.com/nxctf/nxctl) adalah CLI orchestrator untuk lifecycle container Docker,
  TTL challenge, dynamic port, serta ekspor tunnel HTTP dan TCP.
- [NXBOT](https://github.com/nxctf/nxbot) menghubungkan event dengan Discord melalui dashboard,
  live scoreboard, first blood notification, dan ticketing peserta.
- [NXBCL](https://github.com/nxctf/nxbcl) menyediakan launcher untuk blockchain challenge dengan
  runtime EVM yang terisolasi.
- [NXBAK](https://github.com/nxctf/nxbak) membantu backup Supabase menggunakan riwayat snapshot
  berbasis Git, encryption, scheduling, dan GitHub Actions.

NXDOWN, NXAD, dan NXLABS melanjutkan arah yang sama untuk export resource, mode Attack and
Defense, serta eksperimen fitur dan challenge baru.

## Arah Pengembangan

Tujuan NXCTF adalah memberi organizer alur kerja yang lebih terpadu tanpa menutup ruang untuk
kustomisasi dan kontribusi komunitas. Platform utamanya tetap dapat dipakai sendiri, sementara
tool lain dapat ditambahkan sesuai kebutuhan event.

Project, dokumentasi, dan perkembangan terbarunya dapat dilihat melalui
[website NXCTF](https://nxctf.my.id/), [platform publik](https://ctf.nxctf.my.id/), dan
[organisasi NXCTF di GitHub](https://github.com/nxctf).
